## المجلدات

| المجلد | وش فيه |
| --- | --- |
| `day1-challenge` | تحدي الورشة 01 |
| `day1-html-css` | الموقع نهاية الورشة 01 |
| `day2-js` | الموقع نهاية الورشة 02 |
| `final` | الموقع المرجعي كامل |

## كيف تنزّل المشروع

لو ما تستخدم Git: اضغط **Code** ثم **Download ZIP**، وبعدها فك الضغط.

## كيف تشغّله

1. افتح المجلد اللي تبغاه في VS Code.
2. كليك يمين على `index.html` واختر **Open with Live Server**.

## تنبيه

الموقع المرجعي (`final`) عشان ترجع له وتتعلم منه، مو عشان تنسخه وتسلّمه.
